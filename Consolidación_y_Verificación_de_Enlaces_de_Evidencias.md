## Lista de Verificación de Accesibilidad y Calidad

*Para ser diligenciada por el instructor.*

- [ ] Todos los enlaces abren el recurso correcto.
- [ ] No hay errores 404, accesos denegados ni solicitudes de permiso sin resolver.
- [ ] Los documentos se pueden leer y sus imágenes, diagramas y tablas son legibles.
- [ ] El repositorio permite identificar el proyecto, sus ramas y la versión entregada.
- [ ] La evidencia corresponde con el estado real del software.
- [ ] No se presentan pantallas o resultados simulados como si fueran funcionalidades implementadas.
- [ ] La aplicación desplegada inicia y permite verificar las funcionalidades principales.
- [ ] La documentación, el repositorio y la aplicación coinciden en nombres, funcionalidades y versión.
- [ ] No se exponen credenciales, datos sensibles ni información privada.
- [ ] El documento incluye el nombre del proyecto, equipo, fecha de actualización y enlaces directos.
- [ ] Los enlaces se verificaron con el nivel de acceso que se declara en la matriz.
- [ ] El PDF exportado conserva los enlaces y su formato es legible.
