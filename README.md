# Tu Evento — Documentation

Documentation repository for the training project **Tu Evento**, developed as part of the **Technologist in Software Analysis and Development** program at SENA, Sede de la Industria y los Servicios — Neiva, Huila.

**Tu Evento** is an event management solution made up of a mobile app and a web app, allowing management of users, events, and ticket reservations, with storage services on AWS.

# Tu Evento — Documentación

Repositorio de documentación del proyecto formativo **Tu Evento**, desarrollado en el marco del programa **Tecnólogo en Análisis y Desarrollo de Software** del SENA, Sede de la Industria y los Servicios — Neiva, Huila.

**Tu Evento** es una solución de gestión de eventos compuesta por una aplicación móvil y una web, que permite administrar usuarios, eventos y reservas de tickets, con servicios de almacenamiento en AWS.
